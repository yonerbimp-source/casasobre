MIS SOBRES - PWA PARA GITHUB PAGES

1. Descomprime el ZIP.
2. Sube TODOS los archivos y la carpeta icons a un repositorio de GitHub.
3. En GitHub: Settings > Pages > Deploy from a branch > main / root.
4. Abre el enlace de GitHub Pages desde tu celular.
5. Usa "Agregar a pantalla de inicio" / "Instalar app" desde el navegador.

IMPORTANTE:
- Los datos se guardan localmente en el navegador/dispositivo (IndexedDB).
- Usa el botón "Crear respaldo" dentro de la app con frecuencia.
- Las fotos de recibos se guardan en el dispositivo y se incluyen en el respaldo JSON.
- Si borras los datos del navegador sin respaldo, también se pueden perder los datos de la app.
